# WoW Goblin — peon-ping sound pack

Zany male goblin merchant voice from World of Warcraft Classic for [peon-ping](https://github.com/PeonPing/peon-ping).
"Time is money, friend!"

## Install

```bash
peon packs install wow_goblin
peon packs use wow_goblin
```
